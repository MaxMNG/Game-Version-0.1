# CodeStyle.md — стиль кода проекта Version 0.1

GDScript (Godot 4.7). Комментарии и документация — на русском.
Идентификаторы (классы, функции, переменные) — на английском.

## Обязательные правила

1. **Статическая типизация всегда**: переменные, аргументы, возвращаемые значения.
2. **Ноль хардкода**: числа баланса — только в конфигах `.tres` (см. `Docs/Architecture/config-system.md`).
   Допустимы: `0`/`1`/`-1` как индексы и значения «не найдено».
3. **Один класс = один файл**, имя файла = snake_case имени класса (`base_minigame.gd` → `BaseMinigame`).
4. Коммуникация между системами — через сигналы `Events`, не прямыми вызовами.

## Именование

| Сущность | Стиль | Пример |
|----------|-------|--------|
| Классы (`class_name`) | PascalCase | `BaseMinigame` |
| Функции, переменные | snake_case | `change_state`, `trust_value` |
| Константы | SCREAMING_SNAKE | `MAX_SYMBOLS` |
| Приватные члены | префикс `_` | `_is_running`, `_on_started()` |
| Сигналы | snake_case, прошедшее время | `trust_changed`, `minigame_succeeded` |
| Обработчики сигналов | `_on_<кто>_<что>` | `_on_start_button_pressed()` |
| Файлы сцен | PascalCase | `Main.tscn` |
| Файлы скриптов | snake_case | `main.gd` |
| Папки | snake_case | `scripts/autoload/` |

## Порядок секций в файле класса

```gdscript
class_name MyClass        # если есть
extends Control
## Docstring класса (что это и зачем). ## — документирующие комментарии.

# 1. Сигналы
signal something_happened(value: int)

# 2. Константы
const DEFAULT_NAME: String = "x"

# 3. @export-переменные (тюнинг из инспектора)
@export var minigame_id: StringName = &"my_minigame"

# 4. Публичные переменные
var state: int = 0

# 5. Приватные переменные
var _is_running: bool = false

# 6. @onready-переменные (доступ к нодам)
@onready var _container: Control = %StateContainer

# 7. Встроенные колбэки (_ready, _process, ...)
func _ready() -> void:
	pass

# 8. Публичные методы
func start() -> void:
	pass

# 9. Приватные методы и обработчики сигналов
func _on_started() -> void:
	pass
```

## Комментарии

- `##` — документирующие (классы, публичные методы, экспортируемые поля): на русском.
- `#` — поясняющие (нестандартные решения, «почему», а не «что»): на русском.
- Не комментировать очевидное.

## Доступ к нодам

- Внутри своей сцены: `@onready var _x: Label = %UniqueName` (уникальные имена `%`).
- Абсолютные пути `/root/...` и `get_node()` со строковыми путями «наугад» — запрещены.
- Между сценами — только сигналы `Events` и автолоады.

## UI и тема

Источник стиля — `Game/resources/theme/ui_theme.tres` (подключена в `project.godot` →
`gui/theme/custom`). Повторяющийся стиль — только через именованную вариацию типа
(`theme_type_variation = &"TitleLabel"` и т.п.), список вариаций — в теме.

1. Inline `theme_override_*` в `.tscn` — запрещены (исключение — осознанный единичный
   случай, фиксируется в `Docs/Design/visual-language.md`: в сцене комментарий невозможен).
   `add_theme_*_override()` в коде — только со значениями из конфигов `.tres`
   (live-настройка из редакторов) либо как помеченный комментарием `# Исключение K3`
   одноразовый случай; голые числовые литералы запрещены.
2. Размеры, цвета, отступы и длительности анимаций — не литералы (см. «Ноль хардкода»).
3. У каждого `Button` обязательны состояния: normal / hover / pressed / disabled / focus.
4. Focus-навигация (клавиатура/геймпад) — обязательна для всех интерактивных элементов.
5. Минимальная проверка раскладки — 1920×1080 и 1280×720.

## Прочее

- Отступы — **табы** (стандарт GDScript).
- Длина строки — ориентир 100 символов.
- `StringName` (`&"name"`) для идентификаторов, групп, имён сигналов.
- `enum` для конечных наборов состояний (как `Game.State`).
- Не использовать `pass`-заглушки без `TODO`-комментария с пояснением.
