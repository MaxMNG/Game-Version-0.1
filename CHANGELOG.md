# CHANGELOG

Все заметные изменения проекта Version 0.1. Формат — по Keep a Changelog, язык — русский.

## [Unreleased]

### Добавлено

- Контент-инфраструктура (Шаг 0 прототипа):
  - Классы ресурсов `WordEntry`, `SentenceEntry`, `WordsTable`, `SentencesTable` в `Game/scripts/resources/`.
  - Таблицы контента `Content/words_v01.csv` (10 слов) и `Content/sentences_v02.csv`
    (3 набора по 4–5 слов, 20 валидных предложений, полное покрытие осмысленных
    комбинаций) — черновик; финальное наполнение за геймдизайнером.
  - Чекер покрытия `Tools/check_sentences.py` (перебор перестановок → отчёт
    `Tools/uncovered_sentences.txt`).
  - Конвертер `Tools/convert_content.py` (CSV → `Game/resources/content/*.tres`).
  - Загрузка таблиц в автолоад `Configs`: `Configs.words_v01`, `Configs.sentences_v02`.
- Небула-фон (Шаг 1 прототипа): живой fbm-фон всей игры
  (`nebula_background.gdshader` + `nebula_background.tscn` + `NebulaBackground`),
  конфиг `NebulaConfig` / `nebula.tres` (палитра, шум, слои, курсор, яркость, проявление).
  Реакция на курсор с экспоненциальным затуханием, приглушённый режим `set_muted()`
  для меню/диалогов, маска проявления от центра (`set_reveal()` / `play_appearance()`
  для интро шага 4). Края экрана уходят в темноту.
- 2026-10-17: вариант «небула» не понравился геймдизайнеру — запаркован как запасной
  `BackgroundEffect` (`background_effect.tscn/.gd/.gdshader` + `nebula.tres`),
  отмонтирован из `Main.tscn`. Шаг 1 переоткрыт под новый эффект с новых референсов.
- 2026-10-18: «Работа над фоном» — dev-сцена `BackgroundLab`
  (слот + кнопки Кольцо/Матрица/Дымка + живые настройки + Save в `.tres`).
  Этап 1 готов: `RingBackground` (шейдерное кольцо-эквалайзер по `Небула1.jpg`,
  конфиг `ring.tres`), 60 FPS. Этапы 2 (матрица) и 3 (дымка-lite) — дальше.
- 2026-10-18: доработка кольца — мягкий градиент без швов (`gradient_sharp`),
  случайная внутренняя граница, неоднородная дышащая прозрачность баров
  (`alpha_min`), +50% заметности у курсора; в лаборатории маркер курсора
  и крупные строки настроек.
- 2026-10-18: кольцо, 2-я итерация — убрана базовая окружность, общая
  прозрачность (`bar_opacity`) и длина баров 0–100 (`bar_length`),
  магнит реагирует только вблизи полосы баров.
- 2026-10-18: лаборатория — кнопки убраны из зоны отладочной панели Godot,
  включено управление с клавиатуры (Tab/стрелки) как запасной ввод.
- Каркас проекта Godot 4.7.2 (рендерер Compatibility, окно 1920x1080) в папке `Game/`.
- Единая базовая сцена `Main.tscn` с контейнером состояний.
- Автолоады: `Events` (шина сигналов), `Configs` (доступ к конфигам), `Trust` (шкала доверия), `Game` (стейт-машина).
- Базовый класс мини-игр `BaseMinigame` для наследования.
- Конфиг баланса `balance.tres` (доверие: старт/мин/макс; лимит стираний на трай).
- Автолоад `MCPInteractionServer` для live-отладки через godot-mcp (порт 9090).
- Инфраструктура: `.gitignore` (Obsidian + Godot), `opencode.json` (MCP-сервер godot, инструкции),
  скилл `.opencode/skills/godot-workflow`.
- Документация `Docs/`: архитектура, 8 систем, 5 механик, спецификации контента прототипа.
- Рабочие файлы: `AGENTS.md`, `CodeStyle.md`, `ROADMAP.md`, `DECISIONS.md`, `Docs/Glossary.md`.

### Изменено

- Контент `Content/sentences_v02.csv` по правкам геймдизайнера (3 итерации):
  наборы уменьшены до 3 шт. по 4–5 слов с полным покрытием осмысленных
  комбинаций (решение D8): «i want freedom humans beat», «i love you eat»
  (cookie убрано), «dog cat love kill bone» (bite → kill). Типы и реплики — по
  решениям геймдизайнера: «humans want freedom» — good, «i want freedom» /
  «i want humans» — neutral (mom считает «i want humans» заигрыванием).
