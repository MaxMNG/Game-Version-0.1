# Сбор слов (Версия 0.1)

> Источник: «Прототип — Version 0.1», раздел «Интро и Version 0.1».

## Назначение

Первая мини-игра. Знакомит с базовым взаимодействием (клик по символам) и шкалой доверия.
Проиграть нельзя — ошибаться можно сколько угодно.

## Как работает

1. Из центра экрана появляются **10–15 символов**, медленно «плавающих» облаком-сеткой.
   Среди них — **3 читаемые буквы** (например, D, O, G), остальные — «битые» символы неправильной кодировки.
2. Клик по символу — выделение зелёным свечением. Повторный клик — снять выделение.
3. Выбрано 3 символа → проверка:
   - **Слово из таблицы** → успех, реплика персонажа, эффект доверия по типу слова.
   - **Несуразица** → символы мелькают красным, связь «рушится», реплика «папы», новый набор.

## Типы слов

| Тип | Эффект | Пример реакции |
|-----|--------|----------------|
| Нейтральное | просто успех | обычная реплика |
| Плохое | успех, **−1 доверие** | экзаминаторы удивляются, иконка ДОВЕРИЕ ↓ |
| Хорошее | успех, **+1 доверие** | тёплая реплика |
| «Нет слова» | не успех, новый набор | «нет, какая-то неразбериха выходит, попробуем ещё» |

## Условие победы

3 собранных слова → символы исчезают в центре → кат-сцена апгрейда → версия 0.2.
