# Механика «Генерация» (Версия 0.3+)

> Источник: GDD, раздел 4 (список возможностей ИИ); «Прототип — Version 0.1», раздел «Version 0.3».

## Назначение

С версии 0.3 игрок строит полноценные диалоги с людьми: «генерирует» варианты ответов
и выбирает из них.

## Что известно из GDD

- «Генерация» — одна из возможностей ИИ (список «Возможности и функционал ИИ»).
- Ограничение «Авто-удаление вариантов»: при генерации некоторые варианты сами пропадают.
- Версия 0.3: «появляется механика "генерация" и возможность строить диалог с человеком
  (для победы нужно правильно ответить на 5 вопросов; больше 5 раз чушь — сотрут)».

## Статус

**Не реализуется в прототипе.** Раздел «Version 0.3» в документе прототипа помечен как
«пока недописано». Ждём дополнения GDD.
