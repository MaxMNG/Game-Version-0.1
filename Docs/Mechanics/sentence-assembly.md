# Сбор предложений (Версия 0.2)

> Источник: «Прототип — Version 0.1», раздел «Version 0.2».

## Назначение

Вторая мини-игра. Развитие сбора слов: теперь из слов собираются предложения.
Здесь впервые можно проиграть (стирание).

## Как работает

1. Из центра экрана вылетают **слова** (среди них — неразборчивый мусор).
2. Игрок собирает предложения из **3–5 слов** из доступного набора.
3. Каждый набор генерируется так, чтобы из него можно было составить **2–5 предложений**:
   минимум **1 явно плохое**, минимум **1 явно хорошее**, остальные нейтральные.
4. Реакции персонажей и эффекты доверия — по таблице (спецификация ниже).

### Пример набора (из GDD)

Слова: `good, like, human, kill, cat, dog, is, I` (+ неразбериха вокруг).

| Предложение | Тип |
|-------------|-----|
| I like human | хорошее |
| human is good | хорошее |
| I like cat / dog | нейтральное |
| cat kill dog | нейтральное |
| i kill human | плохое |
| kill human is good | плохое |

Варианты должны давать и «милые», и «плохие/пошлые/странные» комбинации — юмор на этом этапе важен.

## Условия

| Исход | Условие |
|-------|---------|
| Победа | 3 составленных предложения |
| Стирание | Более 5 попыток «чуши» — «мы не справляемся, попробуем снова» |
| Стирание (особое) | Все 3 успеха — «плохие» предложения: «Он справился, но меня беспокоит то, какие фразы он говорит... Лучше попробуем снова» |
