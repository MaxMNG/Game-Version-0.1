# Система конфигов

> Требование GDD (раздел 2): **«Ни в коем случае не заводить в хардкод числовые переменные!»**
> Все числа, которые геймдизайнер может захотеть поменять, живут в конфигах.

## Как устроено

1. **Класс ресурса** — в `scripts/resources/` (например, `balance_config.gd`, `class_name BalanceConfig`).
   Все поля — `@export` с русскими docstring-комментариями, сгруппированы `@export_group`.
2. **Файл конфига** — в `resources/configs/` (например, `balance.tres`).
   Правится в инспекторе Godot или текстом.
3. **Доступ** — только через автолоад `Configs`: `Configs.balance.trust_max`.
   `Configs` загружает все .tres один раз при старте.

## Как добавить новый конфиг

1. Создать класс `XxxConfig` в `scripts/resources/xxx_config.gd`.
2. Создать `resources/configs/xxx.tres`, привязать скрипт класса.
3. В `configs.gd` добавить поле и загрузку.
4. В скриптах — читать через `Configs.xxx`. Прямой `load()` вне `configs.gd` запрещён.

## Что является конфигом, а что нет

| Конфиг (нельзя в код) | Не конфиг (можно в код) |
|------------------------|--------------------------|
| Любые числа баланса (доверие, лимиты, таймеры) | 0/1 как индексы, -1 как «не найдено» |
| Количества для победы/поражения | Константы языка/движка |
| Вероятности, веса | Имена сигналов, групп |
| Тексты контента (слова, реплики) | Служебные строки (пути к конфигам) |

## Контент-таблицы (слова, предложения)

Игровой контент массового редактирования (таблицы слов, предложений, реплик)
хранится в CSV в папке `Content/` (корень репозитория) и конвертируется в `.tres`
скриптом `Tools/convert_content.py`. Появится на этапе прототипа —
см. `Docs/Prototype/plan.md` и спецификации в `Docs/Prototype/`.

## Связка «лаборатория → игра» (фон)

Dev-сцена `BackgroundLab` (`scenes/dev/background_lab.tscn`) — пульт настройки
фонов: переключение вариантов, живые слайдеры, кнопка Save. Save пишет через
`ResourceSaver` в `resources/configs/matrix.tres` / `smoke.tres` /
`matrix_smoke.tres` — те же файлы, которые автолоад `Configs` загружает
при старте игры. Отдельный перенос настроек не нужен: настроил в лаборатории,
нажал Save, перезапустил игру — фон в игре обновился.
