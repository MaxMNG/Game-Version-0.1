# Структура папок и сцен

```
Game/
├── project.godot            # Настройки проекта (Godot 4.7, Compatibility, 1920x1080)
│
├── scenes/                  # Все сцены игры
│   └── main/
│       ├── Main.tscn        # ЕДИНСТВЕННАЯ базовая сцена; дети: Background (комбо) + StateContainer
│       └── main.gd
│   # ui/                    # Меню, HUD, баблы диалогов, индикатор доверия (прототип)
│   # minigames/             # Сцены мини-игр версий 0.1, 0.2 (прототип)
│   # effects/               # Фоны (кольцо, матрица, дымка, комбо), вспышки, переходы
│
├── scripts/
│   ├── autoload/            # Синглтоны (см. autoloads.md)
│   │   ├── events.gd        # Шина сигналов
│   │   ├── configs.gd       # Доступ к конфигам
│   │   ├── trust.gd         # Шкала доверия
│   │   └── game.gd          # Стейт-машина игры
│   ├── base/                # Базовые классы для наследования
│   │   └── minigame.gd      # BaseMinigame
│   └── resources/           # Классы конфиг-ресурсов
│       └── balance_config.gd
│
├── resources/
│   └── configs/             # .tres-конфиги баланса (правит геймдизайнер)
│       └── balance.tres
│
├── assets/
│   ├── shaders/             # Шейдеры (небула-фон и др.)
│   ├── fonts/               # Шрифты
│   ├── audio/               # Звуки (в прототипе не используется)
│   └── icons/               # Иконки UI
│
└── addons/
    └── godot_mcp_runtime/   # Автолоад live-контроля для godot-mcp (порт 9090)
        └── mcp_interaction_server.gd
```

## Правила

- Новые сцены кладутся в тематическую подпапку `scenes/`, скрипты — в зеркальную подпапку `scripts/`.
- Одна сущность = одна сцена + один скрипт с тем же именем (snake_case).
- `assets/` — только импортируемые ресурсы, никаких скриптов.
