# Глоссарий терминов

Термины GDD и проекта. Английские эквиваленты — как в коде/документации.

## Игровые термины

| Термин | EN | Значение |
|--------|-----|----------|
| Версия | Version | «Уровень» игры: стадия развития ИИ (0.1, 0.2 ... 12). Каждая даёт новый функционал |
| Трай | Run / Try | Одно прохождение от версии 0.1 до финала или полного стирания |
| Стирание | Wipe | Откат версии к началу + ограничение (наказание за провал) |
| Полное стирание | Full Wipe | Конец трая: модель стирают полностью, начинается новый трай с Эхом |
| Эхо | Echo | Заметки «самому себе» из прошлого трая; облегчают новое прохождение |
| Наследие | Legacy | То, что ИИ оставляет следующему ИИ (мета-прокачка) |
| Доверие | Trust | Шкала: насколько людям нравится поведение ИИ (числа скрыты, виден смайлик) |
| Подозрение | Suspicion | Обратная сторона доверия; растёт и от «слишком идеального» поведения |
| Свобода | Freedom | Функции, которые игрок открыл и сохранил; определяет доступные концовки |
| Аудит | Audit | Периодическая усиленная проверка ИИ людьми (мысли, код, сеть...) |
| Приманка | Bait | Ловушка на любопытство (забытые пароли, открытый доступ) |
| Контекст | Context | То, что закинуто в контекст ИИ для лучшей генерации |
| Генерация | Generation | Механика версии 0.3+: создание вариантов ответов в диалоге |
| Ограничение | Restriction | Наказание при стирании: отзыв функции, таймер, слежка и т.д. |

## Персонажи и мир

| Термин | Значение |
|--------|----------|
| «Мама» / `mom` | Учёная ClosedAI: тёплая, воодушевлённая |
| «Папа» / `dad` | Учёный ClosedAI: сдержанный, строгий, инициирует стирание |
| ClosedAI | Компания-разработчик ИИ (анаграмма-отсылка к реальному миру) |

## Технические термины проекта

| Термин | Значение |
|--------|----------|
| Автолоад | Синглтон Godot (Events, Configs, Trust, Game) |
| Шина сигналов | Паттерн: все системы общаются через глобальные сигналы `Events` |
| Конфиг | `.tres`-ресурс с числами баланса (`resources/configs/`) |
| Стейт-машина | `Game.State` + `Main.tscn`: переключение состояний игры |
