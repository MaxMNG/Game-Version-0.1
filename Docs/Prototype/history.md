## Этап 1. Прототип (готов, шаги 2–9 плана)

Цель: проверить механики и связку «игрок + ИИ-агент-программист». Примитивный визуал,
без звука и сейвов.

- Лаборатория фона + комбо «Матрица + Дым» в `Main.tscn` (правки через лабораторию:
  Save в `.tres` → перезапуск игры).
- Главное меню (печатающийся логотип VERSION 0.1, кнопка «НАЧАТЬ ИГРУ»).
- Интро «Рождение ИИ» (вспышка → появление фона, свободная игра, диалог учёных;
  пропуск кликом/Space).
- Версия 0.1: сбор слов (3 слова для победы, строгий порядок букв + CONFIRM/CLEAR,
  проиграть нельзя).
- Индикатор доверия (смайлик + стрелка).
- Кат-сцена апгрейда до 0.2 (параметризована: тот же оверлей ведёт и в заглушку 0.3).
- Версия 0.2: сбор предложений (3 для победы; >5 чуши или 3 плохих подряд — стирание).
- Экран стирания → рестарт версии (доверие сохраняется).
- Финал: апгрейд 0.2 → заглушка «PROTOTYPE COMPLETE» (клик — возврат в меню).
- Контент-таблицы `Content/*.csv` + конвертер в `.tres`.
- Фоновые комментарии людей (реплики из CSV + реплики dad через диалог-систему).
- Конфиги `menu`, `dialogue`, `intro`, `version1`, `version2`, `cutscene`, `wipe`;
  диалоговая система (`DialogueLine/Bubble/Player`); сигнал
  `Events.version_restart_requested` (рестарт без смены стейта, D13).
- Отклонения D9–D14 (строгий порядок + CONFIRM/CLEAR, лимит чуши >5, доверие
  сохраняется, пропуск кликом/Space, финал-заглушка).
- Пост-прототип (D15–D16): игровой курсор `CustomCursor` + `cursor.tres`;
  click-through фикс (`mouse_filter IGNORE`); безопасная зона спавна 0.1
  (эллипс + `spawn_offset_y`); live-тесты наведения 16/16 и клик-тест пройдены.
- Контент-инфраструктура (Шаг 0): `WordEntry`/`SentenceEntry`/`WordsTable`/
  `SentencesTable`; `words_v01.csv` (10 слов), `sentences_v02.csv` (3 набора,
  полное покрытие, чекер `Tools/check_sentences.py`); конвертер
  `Tools/convert_content.py`; загрузка в `Configs`.

## История фона (итерации, закрыта 2026-10-18)

- Первый вариант «небула» (fbm-чернила) не понравился — запаркован как запасной
  (`background_effect.tscn/.gd/.gdshader` + `nebula.tres`), отмонтирован из `Main.tscn`.
- Лаборатория `BackgroundLab` (слот + кнопки Кольцо/Матрица/Дымка/Комбо + живые
  настройки + Save в `.tres`).
- Кольцо-эквалайзер (шейдер, магнит курсора, `ring.tres`); итерации: мягкий градиент,
  убрана базовая окружность, магнит только вблизи баров.
- Матрица: процедурные псевдо-глифы → статичная сетка настоящих глифов (атлас
  `matrix_glyphs.png`, 94 символа, `Tools/bake_matrix_atlas.py`) → центральное
  свечение + `charge_floor` 0.1.
- Дымка-lite (2 слоя fbm + warp, `smoke.tres`).
- Финал: комбо «Матрица + Дым» (`MatrixSmokeBackground`, `smoke_amount` 0.35),
  фикс полупрозрачности через uniform `amount`; монтаж в `Main.tscn`.
- Связка «лаборатория → игра» задокументирована (`ROADMAP.md`,
  `Docs/Architecture/config-system.md`).
