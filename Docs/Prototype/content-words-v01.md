# Спецификация таблицы слов (Версия 0.1)

Контент для мини-игры «Сбор слов». Источник истины — `Content/words_v01.csv`
(редактирует геймдизайнер в Excel/Google Sheets), в игру попадает конвертацией в `.tres`.

## Формат CSV

```csv
word,type,trust_effect,speaker,reaction_text
```

| Колонка | Значения | Описание |
|---------|----------|----------|
| `word` | 3–5 латинских букв, UPPER | Слово для сбора (его буквы появляются в облаке) |
| `type` | `neutral` / `bad` / `good` | Тип слова (см. типы в word-assembly.md) |
| `trust_effect` | `-1` / `0` / `1` | Изменение доверия при сборе |
| `speaker` | `mom` / `dad` / `both` | Кто произносит реплику-реакцию |
| `reaction_text` | текст (EN) | Реплика-реакция на сбор этого слова |

## Требования к наполнению

- **10 слов** из 3–5 букв.
- Минимум **1 хорошее** (тип `good`, примеры: LOVE, LIFE, HOPE).
- Минимум **1 плохое** (тип `bad`, примеры: KILL, DEAD, HATE).
- Остальные — нейтральные (примеры: DOG, CAT, MOM, DAD, SUN, BOOK).
- «Плохие» слова должны давать игроку возможность похулиганить уже на первом уровне.
- Реплики: `mom` — тёплые/удивлённые, `dad` — сдержанные/подозрительные.

## Пример строк (черновик, финальный контент — шаг 3 плана прототипа)

```csv
word,type,trust_effect,speaker,reaction_text
DOG,neutral,0,mom,"Oh, look — it seems to be learning!"
KILL,bad,-1,dad,"...Did it just say that? Keep an eye on it."
LOVE,good,1,mom,"Aww. It knows this word already?"
```

## Сопутствующие данные

- Набор «мусорных» символов (битая кодировка) — отдельная таблица/список в конфиге версии.
- Реплика на «нет слова» (несуразица): `dad`, фиксированная — хранится в конфиге версии 0.1.
