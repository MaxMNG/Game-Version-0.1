# Спецификация таблицы предложений (Версия 0.2)

Контент для мини-игры «Сбор предложений». Источник истины — `Content/sentences_v02.csv`,
в игру попадает конвертацией в `.tres`.

## Модель данных

Версия 0.2 работает **наборами слов**: из каждого набора можно составить 2–5 валидных
предложений. Таблица описывает и наборы, и валидные предложения в них.

## Формат CSV (черновик)

```csv
set_id,words,sentence,type,trust_effect,speaker,reaction_text
```

| Колонка | Значения | Описание |
|---------|----------|----------|
| `set_id` | число/строка | Идентификатор набора слов |
| `words` | слова через пробел | Все читаемые слова набора (мусор добавляет игра) |
| `sentence` | предложение (EN) | Валидное предложение из слов набора |
| `type` | `neutral` / `bad` / `good` | Тип предложения |
| `trust_effect` | `-1` / `0` / `1` | Изменение доверия |
| `speaker` | `mom` / `dad` / `both` | Кто реагирует |
| `reaction_text` | текст (EN) | Реплика-реакция |

## Правила генерации наборов (требования к наполнению)

- Из набора составимо **2–5 предложений** (строк с одним `set_id` столько же).
- В каждом наборе: минимум **1 `bad`** и минимум **1 `good`**, остальные `neutral`.
- Слова простые и понятные; комбинации должны давать и «милые», и «плохие/пошлые/странные»
  варианты (юмор важен уже здесь).
- Слов в наборе: достаточно для предложений из 3–5 слов + немного лишних для свободы.
- Пример набора из GDD: `good, like, human, kill, cat, dog, is, I`.

## Особые реплики (хранятся в конфиге версии 0.2, не в CSV)

| Ситуация | Кто | Реплика (черновик EN) |
|----------|-----|------------------------|
| «Чушь» собрана | dad | "No, that's gibberish. Again." |
| >5 «чуши» → стирание | dad | "It's not coping. Wipe it, we'll try again." |
| 3 «плохих» подряд → стирание | dad | "It passed, but I don't like the phrases it's making... Let's start over." |
