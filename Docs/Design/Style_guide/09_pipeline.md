## Редакторы (разработка с ИИ в Godot/JS)
Рекомендуемый порядок:
1. **Редактор UI-элементов** (первый). Параметры: срез угла, толщина линии, цвета, glow, состояния. Выход: JSON-токены + пресеты, которые читает Godot. Закрывает 80% работы по консистентности.
2. **Редактор фонов**: частицы, дым, сетка, потоки, слои по версиям 1–12 со слайдером.
3. **Редактор глитч-эффектов** (расширение уже имеющегося редактора эффектов): кубики эффектов (см. 07) и пресеты по событиям.
4. **Превью-экран**: сцена, где можно собрать весь экран из токенов и переключать версию 1–12 и разрешение (1920×1080, 1280×800).

Общий принцип: **один источник правды — `style_tokens.json`**. Редакторы пишут в него, Godot читает. Тогда стиль меняется в одном месте.

Технические заметки:
- Эффекты в Godot: шейдеры `canvas_item` (глитч, scanline, chromatic aberration) и GPUParticles2D.
- Рамки со срезом: собственный `Control` + `draw_polygon`/`draw_polyline`, либо SVG.
- Портреты: `texture_filter = nearest`, масштаб только целыми множителями.
