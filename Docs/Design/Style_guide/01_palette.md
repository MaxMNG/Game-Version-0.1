# 01. Палитра

Hex подобраны по реальным цветам референсов ([NEXUS](../Style_refs/main-visual-ref1.jpeg), [NULL//ECHO](../Style_refs/main-visual-ref2.png), [MIND//OS](../Style_refs/main-visual-ref3.png) — усреднение) и скорректированы. Основа — серо-синий. Остальное точечно.

| --- | --- | --- |

| `line` | `#25495F` | Обычные рамки |
| `line_hi` | `#3A6480` | Рамки в фокусе |

| Токен | Hex | Роль |

| `cyan` | `#59D0F3` | Яркий акцент, glow, текст-заголовки |

## Семантика цветов [РЕШЕНО]
| Смысл | Токен | Hex | Где используется |
| --- | --- | --- | --- |
| Серый и синий | `blue`, серые | см. выше | База: всё нейтральное |
| Безопасность | `safe` | `#8FD3F4` | Системы безопасности людей, аудиты, проверки |
| Хорошее («мы хороший ИИ») | `good` | `#2EE6B8` | Бирюзово-зелёный: доверие растёт, успех, помощь людям |
| Скрытное | `hidden` | `#9B6BF2` | Скрытые действия, шифрование, тайные функции, мысли |
| Агрессия, опасность («мы плохой ИИ») | `danger` | `#E83A5C` | Агрессия, риск, стирание, ошибки |

Дополнительные (приглушённые версии для рамок и фонов): `hidden_dim #453C5B`, `danger_dim #43213A`, `good_dim #124D45`, `safe_dim #2B5565`.

> Красный в референсах ([NEXUS](../Style_refs/main-visual-ref1.jpeg), [NULL//ECHO](../Style_refs/main-visual-ref2.png)) склоняется к розово-малиновому (`#E8507C`). Взял чуть более красный `#E83A5C`, чтобы читалось как «опасность». Если хочется малиновее, поменяем одно значение в токенах.

## Шкалы
| Шкала | Цвета |
| --- | --- |
| Доверие / подозрение (одна шкала) | Низко: градиент `hidden` → `danger` (фиолетово-красный). Середина: `blue`. Очень высоко: `safe` → `good` (светло-голубой, близкий к зелёному) |
| Свобода | Одноцветная `cyan`, без градиента |

## Правила использования
- На типичном экране: **90% серо-синее**, 8% `blue/cyan`, 2% смысловые цвета. Смысловой цвет должен выделяться за счёт редкости.
- Свечение (glow) = цвет элемента с прозрачностью ~30–40% и размытием. Конкретные числа в токенах.
- Нельзя два смысловых цвета рядом без причины (например, `good` и `danger` рядом только при явном конфликте).
- Текст на тёмном — минимум контраст 4.5:1 (`text` и `text_dim` проходят).

## Цвет по версиям [ПРЕДЛОЖЕНИЕ]
| Версии | Что доступно |
| --- | --- |
| 1 | Только `void`, `blue`/`cyan` (одна точка и частицы) |
| 2–3 | + серые поверхности, `good` (первые успехи) |
| 4–6 | + `safe` (появляются аудиты) |
| 7–9 | + `hidden` (шифрование, скрытность), редкие вспышки `danger` |
| 10–12 | `hidden` и `danger` занимают заметную долю: фоновая подсветка, рамки, свечение голограммы |

Это не жёсткий запрет, а **бюджет акцентов**: на ранних версиях игра просто не нуждается в этих цветах.

## Доступность
Смысл не передаётся только цветом: дублируем иконкой, формой, текстом. Для дальтоников красный и зелёный различаем ещё и иконкой/формой.
