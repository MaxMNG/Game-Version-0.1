# 07. Эффекты и анимации

Длительности, интенсивность, цвета — в токенах/конфигах. Здесь только логика.

## A. Экранные эффекты (на весь экран) [РЕШЕНО: нужны]
| Событие | Цвет | Эффект |
| --- | --- | --- |
| **Стирание** (откат версии) | `danger` + белая вспышка | Сильный глитч, RGB-расслоение, UI «рассыпается» на пиксели и гаснет в чёрный, затем медленная пересборка |
| **Аудит** | `safe` | Горизонтальная линия-скан проходит по экрану, панели мигают светло-голубым, лёгкая рамка по краю экрана |
| **Баг/ошибка** | `danger` | Короткий глитч, смещение строк, мигание панелей, шум |
| **Эмоция: симпатия** | `good` + тёплый оттенок | Мягкая пульсирующая вспышка от центра, частицы поднимаются вверх |
| **Эмоция: злость** | `danger` | Резкие красные импульсы по краям, дрожание, искажение |
| **Скрытное действие** | `hidden` | Фиолетовое затемнение краёв, панели на миг теряют линии |
| **Открытие функции / новая панель** | `cyan` | «Вспышка открытия»: контур прорисовывается по линии, затем заполняется |
| **Апгрейд версии** | `cyan` → белый | Пиксели собираются, фон «проясняется», UI становится чётче |
| **Подозрение растёт** | `hidden`→`danger` | Медленная пульсация краёв, виньетка краснеет |

Эффекты должны быть **читаемыми, но не мешающими игре**: длительность короткая, интерактивность блокируется только если это нужно по смыслу (стирание).

## B. Состав эффектов (для редактора)
Базовые «кубики»: `glitch_rgb_split`, `scanline_sweep`, `flash`, `vignette_pulse`, `pixel_dissolve`, `noise_burst`, `panel_blink`, `edge_glow`, `shake`, `particle_burst`. Каждое событие = пресет из этих кубиков.

## C. Микро-анимации интерфейса [РЕШЕНО: входят в гайдлайн]
| Элемент | Анимация |
| --- | --- |
| Панель появляется | Контур прорисовывается из угла (draw-on), затем fade заливки |
| Панель закрывается | Обратно, быстрее |
| Кнопка hover | Подъём яркости линии, лёгкий glow |
| Кнопка click | Короткая вспышка заливки, смещение 1–2 px |
| Пункт меню | Индикатор слева «выезжает» |
| Шкала меняется | Плавный проезд заливки, на конце короткая вспышка |
| Уведомление (смайлик+стрелка) | Всплывает, лёгкий bounce, растворяется |
| Плитка выбрана | Свечение включается, линия к предыдущей прорисовывается |
| Чип контекста drag | Поднимается (масштаб + тень), цели подсвечиваются |
| Чип брошен | Прилипает с лёгким «щелчком» (масштаб-пульс) |
| Новый комментарий | Выезжает сверху, портрет моргает рамкой |
| Объект «летит в центр» | Дуга полёта + след из частиц, в центре «разворачивается» |
| Idle | Едва заметное мерцание линий, дрейф частиц фона |

## D. Правила движения
- Быстро и чётко (ease-out), лёгкая «цифровая» дискретность допустима (ступенчатые шаги у мерцаний).
- Никаких «резиновых» мультяшных пружин в панелях. Лёгкий bounce только у иконок-уведомлений.
- Версии 1–3 — медленнее и мягче, 7–12 — резче и с глитчем. Параметр `animation_style_by_version`.
- Режим «уменьшить эффекты» в настройках (мерцание, тряска, вспышки): важно для доступности.

## F. Реестр эффектов (K7, переедет в `visual-language.md` при закрытии K1)
Эффект без записи в реестре в игру не попадает.

| Имя | Где играет | Размер | Длит. | Громк. | JSON | `.tres` |
| --- | --- | --- | --- | --- | --- | --- |
| `wipe_screen` | `wipe_screen.tscn` (поверх затухания) | 512, ячейка 256 | 0.9 с | 2 | `Game/assets/effects/src/wipe_screen.json` | `resources/configs/fx/wipe_screen.tres` |
| `upgrade_cutscene` | `upgrade_cutscene.tscn` (момент сжатия) | 512, ячейка 256 | 0.9 с | 2 | `Game/assets/effects/src/upgrade_cutscene.json` | `resources/configs/fx/upgrade_cutscene.tres` |

Цикл пилота: править JSON в репозитории → `node tools/validate.mjs` (в папке
Effector) → экспорт PNG из вкладки Atlas → `python Tools/import_afx_atlas.py <имя>` →
атлас + `SpriteFrames` + привязка в `fx/*.tres`. PNG-экспорт — вручную в браузере
(порт 5179, `?open=<имя>.json&tab=atlas`); остальное автоматизировано.
Проигрыватель: `scenes/effects/fx_sprite.tscn` (`FxSprite`: `play_once`/`play_loop`/`stop`,
`finished`, `set_muted`). Границы: шейдерные фоны (`matrix`, `smoke`, `ring`,
`scanline`) Effector не заменяет.
