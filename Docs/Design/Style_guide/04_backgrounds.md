# 04. Фоны и окружение

ИИ не покидает киберпространство. Фон = **его внутренняя среда**, а не реальная комната. Реальный мир — только через камеры, чаты, сайты.

## Слои фона (снизу вверх)
1. **Void:** базовая заливка `void`/`bg`.
2. **Glow:** радиальная подсветка в центре (`bg_deep_blue`) — фокус на рабочую область.
3. **Частицы/дым:** медленный дрейф, шейдер или GPUParticles. Плотность, цвет, скорость — токены.
4. **Структура:** сетка, потоки данных, силуэты серверов в глубокой расфокусировке (появляются с версий).
5. **Акцентные огни:** редкие пятна `hidden`/`danger`/`safe` вдали (боке).
6. **Виньетка и зерно:** лёгкое затемнение краёв, очень слабый шум.

Правило: фон **не должен спорить с UI**. Самая светлая часть фона всегда темнее рамок панелей.

## Эволюция по версиям [ПРЕДЛОЖЕНИЕ, на основе твоего описания]
| Версии | Фон |
| --- | --- |
| 1 | Чернота, редкие частицы, дым. Одна слабая точка синего |
| 2–3 | Частицы чуть упорядочены, мягкие потоки, первые линии |
| 4–6 | Тонкая сетка, вертикальные потоки данных («матрица»), намёк на глубину |
| 7–9 | Размытые силуэты серверных стоек/кабелей (задний план [NULL//ECHO](../Style_refs/main-visual-ref2.png) и [MIND//OS](../Style_refs/main-visual-ref3.png)), глитч-вспышки |
| 10–12 | Плотная архитектура данных, фиолетовое и красное освещение, угрожающая глубина |

## Параметры для редактора фонов
`particle_density`, `particle_speed`, `smoke_amount`, `grid_opacity`, `data_stream_count`, `structure_layer_opacity`, `accent_light_count`, `accent_light_colors`, `vignette`, `noise`, `blur_depth`, `version_stage`. Редактор должен показывать фон по версиям 1–12 с ползунком.

## Центр и подсветка
Центральная область имеет мягкую подсветку (как центр [схемы](../Style_refs/main-screen-scheme-1.png)), усиливающуюся, когда игрок занят мини-игрой, и гаснущую при пустом центре.

## Кат-сцены и камеры
Отдельные пиксель-арт сцены (см. персонажей). Рамка камеры: тонкий контур, метка REC/CAM, лёгкие scanlines, цветокоррекция в сине-серую гамму.
