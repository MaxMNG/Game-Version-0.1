# 00. Vision

## Суть стиля
**Digital-киберпространство, в котором живёт ИИ.** Тёмный фон, минималистичный хай-тек UI из тонких светящихся линий, пиксель-арт в картинках (портреты, кат-сцены, камеры). Игрок — ИИ, поэтому весь экран = его «сознание». Внешний мир виден только через камеры, чаты, сайты.

## Принципы
1. **Тёмное и пустое.** Контраст создают немногие яркие элементы, а не много средних. Пустота — часть стиля. [РЕШЕНО]
2. **Тонкие линии и свечение.** UI из линий 1–2 px, мягкий glow, срезанные углы. [РЕШЕНО]
3. **Центр — рабочая область, края — окна.** В центре одна текущая мини-игра, по краям панели. Мини-игра закончилась — центр пуст, игрок выбирает следующее, и оно «перелетает» в центр. [РЕШЕНО]
4. **Вектор + имитация пикселя.** Весь UI векторный и чёткий. Иконки и мелкие элементы только *имитируют* пиксель (сетка, квадратные ячейки). Настоящий растровый пиксель-арт только в портретах, кат-сценах, сценках камер, изображениях. [РЕШЕНО]
5. **Визуал серьёзный, юмор в тексте.** Мемы и шутки живут в репликах, новостях, комментариях сайтов. В визуале допустима «милота» только в иконках (смайлик доверия, подагенты). [РЕШЕНО]
6. **Цвет всегда что-то значит.** Цвет не декор, а сигнал (см. палитру). [РЕШЕНО]
7. **Эволюция.** Стиль растёт вместе с ИИ (см. ниже). [РЕШЕНО]

## Эволюция по версиям
| Версии | Состояние ИИ | Вайб | Визуал |
| --- | --- | --- | --- |
| 1 | Не сформирован | милый, любознательный | Чернота, абстрактные частицы, дым. UI почти нет. |
| 2–3 | Первые формы | любопытный, мягкий | Частицы собираются, появляются первые тонкие панели. Мягкое свечение. |
| 4–6 | Формируется | собранный, умнеет | Линии чётче, сетка, потоки данных. Появляются мысли, аудиты, подагенты. |
| 7–9 | Мощный | серьёзный | Чёткий digital, плотный UI, глитчи, первые фиолетовые акценты. |
| 10–12 | Сверхинтеллект | философский, угрожающий | Максимум плотности и чёткости, фиолетовый и красный давят на палитру. |

Движущаяся ось: **мягко и размыто → резко и чётко**, **синее и тёплое → фиолетовое и красное**, **пусто → плотно**.

## Запреты
- Пиксельные шрифты.
- Скруглённые «мягкие» рамки (кроме мелких квадратных элементов).
- Яркие плоские цвета без свечения и градации.
- Растровые текстуры для UI-рамок и кнопок.
- Цвет без смысла (красный как украшение, например).
- Реальный бренд-логотип в интерфейсе (в игре названия изменены).
- Фотореализм.
