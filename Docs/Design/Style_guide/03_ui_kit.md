# 03. UI-кит

## Экран (база 1920×1080) [РЕШЕНО, по схеме]
```
┌───────────────────────────────────────────────────────────────┐
│ [ШКАЛЫ]             VERSION 0.1             [КОММЕНТАРИИ]     │
│ [МЕНЮ]                                      [портрет человека]│
│                                                               │
│                  ЦЕНТР: РАБОЧАЯ ОБЛАСТЬ                       │
│                  (мини-игра / кат-сцена /                     │
│                   чат / взлом / пусто)                        │
│                                                               │
│ [ИИ-ПОДАГЕНТЫ]                              [КОНТЕКСТ n/N]    │
└───────────────────────────────────────────────────────────────┘
```
- По краям окна, в центре одна активная задача.
- Задача закончилась → центр пуст. Игрок выбирает следующее, объект «перелетает» в центр.
- Отступ от края экрана (safe margin) — в токенах. Для Steam Deck и телевизоров держим важное не вплотную к краю.

## Масштабирование (Godot)
- Базовое разрешение 1920×1080, stretch mode `canvas_items`.
- Steam Deck: 1280×800 (16:10). Верстаем на якорях (anchors/containers), а не абсолютных координатах, чтобы панели не вылезали на 16:10. Центральная область эластичная, панели по углам фиксированы.
- Мелкий текст не уменьшаем ниже минимума (см. типографику).
- **Геймпад обязателен [РЕШЕНО]:** у каждого интерактивного элемента есть состояние **Focus** (яркая рамка `cyan`, заметнее hover), порядок навигации задаётся в сцене. Drag-n-drop дублируется режимом «взять → выбрать цель → подтвердить». Подсказки кнопок (A/B/X/Y) показываем по текущему устройству.

## Рамки и углы [РЕШЕНО]
- **Основные панели:** скошенные («обрезанные») углы, чаще по диагонали (левый-верхний и правый-нижний, как на [NEXUS](../Style_refs/main-visual-ref1.jpeg) и [MIND//OS](../Style_refs/main-visual-ref3.png)). Размер среза — токен.
- **Мелкие элементы** (плитки, чипы, теги): квадратные углы, возможно микро-срез.
- Линия 1–2 px, цвет `line` / `line_hi`, активное — `blue`/`cyan` с glow.
- Заливка панели: `surface` с прозрачностью (видно фон), опциональный тонкий внутренний градиент.
- Декор углов: 1–2 маленькие «скобки»/засечки на углах и тонкие метки — как на [NEXUS](../Style_refs/main-visual-ref1.jpeg) и [NULL//ECHO](../Style_refs/main-visual-ref2.png), без перегруза.

Реализация в Godot: фиксированный срез → 9-slice из SVG/текстуры или `draw_polygon` в собственном Control. Для масштабируемых рамок лучше второе, чтобы линия оставалась тонкой.

## Состояния элементов
| Состояние | Вид |
| --- | --- |
| Normal | `line`, `surface`, текст `text_dim` |
| Hover | `line_hi`, лёгкий glow, текст `text` |
| Focus (геймпад/клавиатура) | `cyan`, усиленный glow, маркеры-скобки по углам |
| Pressed | Вспышка заливки `blue` 20%, смещение на 1–2 px |
| Active/Selected | `cyan`, стабильный glow, маркер-индикатор |
| Disabled | `line_dim`, текст `text_off`, без glow |
| Locked (ещё не открыто) | Рамка пунктиром, иконка замка или «?» |
| Alert | Мигание смысловым цветом (`danger`/`safe`/`hidden`) |

## Кнопки
- Скошенный угол, заглавный текст с трекингом, иконка слева, стрелка `>` справа для действий.
- Главная кнопка (одна на экран): заливка `blue` 15–20%, рамка `cyan`.
- Второстепенные: только контур.

## Меню (слева сверху) [РЕШЕНО, по схеме]
Пункты: **Сознание, Память, Навыки, Функции, Система**. Пункты открываются по мере версий. Активный пункт — подсветка линией слева + `blue` заливка. Иконки — векторная имитация пикселя.

## Шкалы [РЕШЕНО]
| Шкала | Вид |
| --- | --- |
| Доверие/подозрение | Одна горизонтальная полоска, сегментированная. Цвет по уровню (см. палитру). Иконка-смайлик рядом |
| Свобода | Полоска `cyan`. Иконка рядом |

- Числа (`78%`) **показываем** [РЕШЕНО]. Флаг `show_numbers` в конфиге, чтобы отключить без правки UI.
- Сегменты: тонкие деления, как нижние шкалы на [NULL//ECHO](../Style_refs/main-visual-ref2.png).

### Временные уведомления об изменении [РЕШЕНО]
- **Доверие:** смайлик + стрелка вверх/вниз. Цвет по направлению (вверх — `good`/`safe`, вниз — `hidden`/`danger`).
- **Свобода:** иконка свободы + стрелка вверх/вниз (`cyan`).
- Появление: всплывает возле шкалы, держится ~1–2 с, растворяется. Тайминги в токенах.

## Иконки [РЕШЕНО: векторные, косят под пиксель]
- Сетка 16×16 или 24×24 клеток, фигура собрана из квадратов или 45°-линий, без плавных кривых.
- Единая толщина линии, срезанные углы, без градиентов внутри (только glow снаружи).
- «Милота» допустима у: смайлика доверия, подагентов.
- Делаем как **SVG**, чтобы масштабировались без размытия и красились токенами.

## Плитки мини-игры (центр) [по схеме]
- Квадрат с небольшим радиусом/срезом, символ по центру.
- Неактивные: почти растворены в фоне (`line_dim`, прозрачность). Выбранные: `good` свечение, соединительные линии между ними.
- Вокруг группы мягкое свечение, как «облако мысли».

## Контекст (справа внизу) [РЕШЕНО, по схеме]
- Заголовок «Контекст» + счётчик `n / N`.
- Панель с чипами (слово, иконка, зашифрованная строка вида `#@1)nm`).
- Drag-n-drop: чип «поднимается» (тень, масштаб +), цели для сброса подсвечиваются. Заполненность лимита видна в счётчике, при переполнении — предупреждение цветом.

## Комментарии людей (справа вверху) [РЕШЕНО: пузыри не нужны]
- Компактная карточка: **портрет (пиксель)** + строка текста. Без «хвостиков» и скруглённых пузырей.
- Рамка как у обычного элемента, но с меткой цвета по тону (одобрение `good`, насмешка/сомнение `safe`, угроза `danger`).
- Новый комментарий появляется сверху, старые уезжают вниз и гаснут.
- Максимум одновременно — в токенах.

## ИИ-подагенты (слева снизу)
Пока «некая панель с контентом». Не детализируем. Только общие правила рамки и заголовка. Потом: милые иконки-агенты, возможно пиксельные.

## Фоны панелей и «стекло»
Панели полупрозрачные, фон за ними слегка размыт (blur-шейдер при необходимости). На ранних версиях панелей меньше и они тоньше.

## Плотность UI по версиям [ПРЕДЛОЖЕНИЕ, привязка к GDD]
| Версии | Что есть на экране |
| --- | --- |
| 1 | Только центр. Максимум шкала |
| 2 | + шкалы, комментарии |
| 3 | + панель мыслей (по GDD с v3), меню |
| 4–6 | + контекст, подагенты, аудиты (v5), эмоции (v6) |
| 7+ | + шифрование (v7), мониторинг, камеры, плотный экран |
| 10–12 | Максимальная плотность, как [NEXUS](../Style_refs/main-visual-ref1.jpeg) – [MIND//OS](../Style_refs/main-visual-ref3.png) |

Каждый новый элемент появляется с «вспышкой открытия» (см. эффекты), чтобы игрок заметил.
