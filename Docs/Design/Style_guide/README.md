# Version 0.1 — Style Guide

Главный документ визуального стиля. Читай только нужный файл.

| Файл | Содержание |
| --- | --- |
| `00_vision.md` | Суть стиля, принципы, запреты, эволюция по версиям 1–12 |
| `01_palette.md` | Палитра, роли цветов, шкалы, цвет по версиям |
| `02_typography.md` | Шрифты, размеры, регистр, языки (RU/EN/CJK) |
| `03_ui_kit.md` | Экран, рамки, кнопки, шкалы, иконки, контекст, комментарии |
| `04_backgrounds.md` | Фоны и окружение по версиям |
| `05_characters.md` | Люди: портреты, эмоции, камеры |
| `06_ai_hologram.md` | Образ ИИ: точка → смайлик → лицо → голограмма |
| `07_effects_animation.md` | Экранные эффекты и микро-анимации |
| `08_prompts.md` | Промпты для точечных референсов (GPT-image / NanoBanana) |
| `09_pipeline.md` | Инструменты и редакторы |
| `10_open_questions.md` | Что ещё не решено |
| `style_tokens.json` | Числа и цвета для конфигов (Godot и редакторы) |

**Правило проекта (из GDD):** никаких числовых значений в хардкоде. Все цвета, размеры, тайминги берутся из `style_tokens.json` / конфигов. Значения в этих документах — стартовые, их можно менять в конфиге.

Статусы в документах: **[РЕШЕНО]** — сказал автор, **[ПРЕДЛОЖЕНИЕ]** — моя гипотеза, нужно подтверждение.
