# 05. Персонажи (люди)

## Стиль [РЕШЕНО: базовый референс — фрагмент Operator 07 слева снизу [NULL//ECHO](../Style_refs/main-visual-ref2.png), Kira (слева снизу [NEXUS](../Style_refs/main-visual-ref1.jpeg)) тоже подходит]
- **Пиксель-арт портреты** с реалистичными пропорциями (не обязательно аниме).
- Взрослые, серьёзные выражения, детальные лица, лёгкий кинематографический свет.
- Свет: холодный синий контровый и боковой фиолетово-голубой, у лица мягкие тени. Фон портрета тёмный с синей рамкой.
- Одежда: тёмные куртки, высокие воротники, технологичные детали, без ярких цветов. Яркий акцент допустим в глазах (cyan) для «ИИ-связанных» персонажей.

## Где видим людей
| Контекст | Формат |
| --- | --- |
| Чаты, комментарии | Портрет-аватар |
| Кат-сцены | Крупные пиксельные иллюстрации |
| Камеры | 2D пиксельные сценки с анимацией (люди что-то делают, события в мире) |
| Сайты | Аватарки пользователей, мелкие, могут быть упрощены |

## Портрет
- Пиксель-арт растровый, масштабируется **целым множителем**, фильтр `nearest`, чтобы пиксели не мылились.
- Стартовая рекомендация [ПРЕДЛОЖЕНИЕ]: исходник ~128×160, показ ×2 в UI. Финал после первого теста.
- Рамка портрета: тонкая линия `line_hi` и срезанный угол, как у UI.
- Пиксель-размер должен быть **одинаков** у всех портретов (единый «размер пикселя»), иначе стиль разваливается.

## Эмоции [ПРЕДЛОЖЕНИЕ]
Базовый набор: нейтральный, доволен, грустный, злой, удивлён, подозрительный. Для ключевых персонажей, возможно, + влюблённый, испуганный. Хватит смены глаз/бровей/рта на одном исходнике, чтобы сохранить стиль и сократить объём.

## Цвета по отношению
Цветом кожи и палитрой персонажа не кодируем. Отношение к ИИ — цветом рамки/метки (`good` — симпатия, `safe` — формально-нейтрален, `hidden`/`danger` — недоверие и вражда).

## Камеры: стиль сценок
- Пиксель-арт 2D, вид сверху/сбоку, лёгкая анимация (2–4 кадра цикла).
- Фильтр «CCTV»: приглушённая сине-серая гамма, scanlines, лёгкий шум, метка времени.
- Один «размер пикселя» со всеми остальными пиксель-артами.

## Пример персонажа (для шаблона)
