# 06. Образ ИИ (голограмма)

ИИ **не виден игроку в игровом процессе** (игрок и есть ИИ). Образ показывается в **главном меню, новостях, кат-сценах** (лаборатория, люди подходят к голограмме). [РЕШЕНО]

Референс: [MIND//OS](../Style_refs/main-visual-ref3.png) (голова в капсуле, matrix-поток, голографические подписи). Капсула и кольца также видны на [NEXUS](../Style_refs/main-visual-ref1.jpeg) и [NULL//ECHO](../Style_refs/main-visual-ref2.png). [РЕШЕНО]

## Эволюция образа [РЕШЕНО]
| Стадия | Образ | Версии (предложение) |
| --- | --- | --- |
| 1 | Маленькая синяя точка, частицы вокруг | 1 |
| 2 | Синий смайлик (простая «милая» форма из пикселей) | 2–3 |
| 3 | Лицо: пиксельное, ещё простое | 4–6 |
| 4 | Лицо + голографические эффекты (падающие символы, распад пикселей, сканлайны) | 7–9 |
| 5 | Усложнённая форма: кристалл/трещины, больше деталей, угрожающие акценты | 10–12 |

## Общие правила
- Форма и цвет голограммы — на основе `blue`/`cyan`; на поздних версиях в неё проникают `hidden` и `danger` (трещины, подсветка снизу).
- Голограмма всегда в капсуле или на платформе с кольцами ([NEXUS](../Style_refs/main-visual-ref1.jpeg) – [MIND//OS](../Style_refs/main-visual-ref3.png)).
- Лицо **нейтральное, без пола и возраста**, слегка андрогинное, с светящимися глазами.
- Пиксельный стиль: крупные квадратные пиксели, лицо читаемое, часть пикселей «осыпается».
- Подписи вокруг (`AI CORE`, `STABLE 98.7%`, список `ANALYZE / LEARN / EVOLVE`) — типографика из гайда. В прод-версии тексты идут через локализацию.

## Поведение (анимация)
| Состояние | Анимация |
| --- | --- |
| Idle | Медленное «дыхание» свечения, дрейф пикселей |
| Говорит | Пульсация глаз/рта, всплески в потоке данных |
| Тревога | Дрожание, красные вспышки по краям |
| Распад | Лицо рассыпается на пиксели (стирание) |
| Сборка | Пиксели собираются в лицо (запуск, апгрейд версии) |

## Для редактора
Параметры: `stage`, `pixel_size`, `decay_amount`, `glow_color`, `matrix_density`, `crack_amount`, `eye_brightness`, `ring_count`, `platform_style`.
