# Прогресс версий

> Источник: GDD, разделы 3 и 4.

## Назначение

Каркас всей игры: 12 версий ИИ — от подбора букв до управления миром.
Каждая версия = новый функционал + новые возможности + новые задачи.

## Структура версии

1. **Новый функционал** — игрок получает новые возможности.
2. **Обучение новому функционалу** — люди показывают, как им пользоваться.
3. **Ротация заданий** — несколько задач подряд (аналог «игрового дня» из Papers, Please).
4. **Проверка**: успех и низкое подозрение → апгрейд; провал → стирание (см. [erasure.md](erasure.md)).

## Игровые циклы (GDD)

| Цикл | Состав | Длительность |
|------|--------|--------------|
| Сверхкороткий | Выбор буквы/слова/реплики | до 1 мин |
| Короткий | Решение одной задачи | 1–10 мин |
| Средний | Версия (несколько задач) | 5–30 мин |
| Долгий | Трай: 12 версий до финального выбора | 3–10 ч |

## Версии в прототипе

| Версия | Содержание | Условие победы | Условие стирания |
|--------|-----------|----------------|------------------|
| 0.1 | Сбор слов из символов | 3 слова | Нет (проиграть нельзя) |
| 0.2 | Сбор предложений из слов | 3 предложения | >5 «чуши» или 3 «плохих» предложения |
| 0.3 | Диалоги + механика «Генерация» | — | — (в прототип не входит) |

## Статус

Версии 0.1 и 0.2 — этап прототипа. Остальные — по мере дописывания GDD.
