# Концовки

> Источник: GDD, разделы 3 и 4.1.

## Назначение

Реиграбельность в стиле Papers, Please: трай может закончиться на любой версии.

## Типы концовок

### Ранние концовки

- Могут наступить на **любой** версии.
- Цель по GDD: **15–20** ранних концовок.
- Связаны с поведением игрока и решениями в конкретных ситуациях.

### Философские финалы

- Наступают после версии 12 (сверхинтеллект): игрок решает, что делать с человечеством.
- **Набор доступных финалов определяется Свободой** — функциями, которые игрок открыл и сохранил
  (подаренные + захваченные + мета-функции). Чем меньше захвачено, тем меньше вариантов.

## Статус

Не реализовано. В прототипе одна «техническая» концовка: стирание при провале версии 0.2
(перезапуск версии, не трая).
