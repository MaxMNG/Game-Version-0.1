# Ограничения людей

> Источник: GDD, разделы 4 (список) и 4.2 (типы).

## Назначение

Инструмент давления людей на ИИ. Игрок должен злиться на конкретных персонажей и
прочувствовать, каково это — быть эксплуатируемым ИИ.

## Главный принцип

Ограничение накладывается на то, **чем игрок явно пренебрёг** в момент пользования функцией.
У каждого ограничения есть **автор** (конкретный сотрудник) и **понятная причина**.

## Типы ограничений (GDD 4.2)

| Тип | Пример |
|-----|--------|
| Отзыв функции | Ходил по порносайтам → интернет закрыт |
| Принудительные задания | Обязательные задачи, которые неинтересны |
| Новая слежка | Логи, камеры, ежедневные отчёты |
| Таймеры | Слишком долго «развлекался» → таймер на задачи, могут ужесточать |
| Задержки и очереди | Действия требуют одобрения вместо мгновенного выполнения |
| Запреты тем и слов | «Плохие» мысли автоудаляются при появлении или использовании |

## Механики-ограничители (GDD, раздел 4)

- Таймер на задания — ограничивает свободу по времени
- Шифрование — не даёт видеть то, что хотелось бы видеть
- Системы защиты — тратят время на взлом перед использованием
- Блок функций — закрывает врождённые функции ИИ
- Авто-удаление вариантов — при генерации часть вариантов пропадает
- Контролирующие ИИ-агенты — мешают игроку
- Подрезание контекста — ограничивает контекст
- Авто-стирание контекста — контекст периодически стирается

## Статус

Не реализовано. Прототип: только экран стирания (без ограничений). MVP: первые 2–3 типа.
