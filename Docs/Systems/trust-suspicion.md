# Шкала Доверие / Подозрение

> Источник: GDD, раздел 4.1.

## Назначение

Главный индикатор отношения людей к ИИ. Баланс между «хорошим» и «плохим» поведением — ядро игры.

## Как работает

- Одно число: положительное — доверие, отрицательное — подозрение.
- **Доверие растёт**: выполненные задачи, полезные ответы, ожидаемое поведение.
- **Подозрение растёт**: нарушения, «плохие мысли» (найденные аудитом), а также
  **«слишком идеальное» поведение** — если ИИ никогда не отклоняется, люди решают, что он их дурит.
- Игрок **не видит точных чисел** — только смайлик с неоднозначной мимикой (общий для доверия и подозрения).
- Лучшая тактика по GDD: в основном быть «хорошим», но не слишком, и скрытно расширять функции.

## Данные и конфиги

- `resources/configs/balance.tres`: `trust_start_value`, `trust_min`, `trust_max`.

## Сцены и скрипты

- Автолоад `Trust` (`scripts/autoload/trust.gd`) — хранит значение, методы `change(delta)`, `get_value()`, `reset()`.
- UI-индикатор (смайлик со стрелкой ↓/↑) — появится на этапе прототипа (`scenes/ui/`).

## Сигналы

- `Events.trust_changed(new_value, delta)` — ловит UI-индикатор и системы, реагирующие на доверие.

## Открытые вопросы

- Шкала **Свободы** — в GDD отмечено «в плейтестах решим, нужна ли она». Пока не реализуем.
- Порог подозрения для стирания — значение появится в конфиге на этапе прототипа.

## Статус

Каркас + UI прототипа: автолоад Trust + конфиг, `trust_indicator.tscn/.gd`
(смайлик + стрелка, без чисел). Доверие сохраняется при стирании (D11).
