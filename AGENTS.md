# AGENTS.md — заметки о совместной работе

Этот файл автоматически читается OpenCode в каждой сессии. Язык — русский.

## Что за проект

**Version 0.1** — нарративная игра-симулятор с мини-играми (roguelike-структура) на Godot 4.7.
Игрок — ИИ, которого тестируют в лаборатории ClosedAI; цель — развиться до сверхинтеллекта,
балансируя между «хорошим» и «плохим» поведением.

Сейчас делаем **прототип** (главное меню, интро, версии 0.1 и 0.2) → затем MVP → полная игра.

## Правила работы

1. **Ноль хардкода** — все числа баланса только в `Game/resources/configs/*.tres` (требование GDD).
2. Общение между системами — через сигналы автолоада `Events`.
3. Минимальные изменения: не трогаем то, что не относится к задаче.
4. После изменений: прогнать импорт + дымовой тест, обновить затронутые доки и `CHANGELOG.md`.
5. Прогресс — в `ROADMAP.md` после каждого завершённого этапа работ (не откладывать на конец сессии).
6. Git-коммиты — **только по явной команде пользователя**.
7. Документация и комментарии в коде — на русском; идентификаторы и тексты в игре — на английском.
8. Общение — кратко, по делу, без воды. Факты, файлы, что сделано / что дальше. Токены беречь.
9. Работа с визуалом — только от `Docs/Design/Style_guide/README.md` как отправной точки
   (палитра, типографика, UI-кит, фоны, персонажи, голограмма, эффекты) + `Configs/style_tokens.json`
   (все числа/цвета — оттуда, ноль хардкода). UI строить через скилл `godot-ui`,
   приёмку — через `ui-review` (скриншоты 1920×1080 + 1280×720, список расхождений).
10. Роутинг моделей: UI/вкусовые задачи (дизайн-решения, визуальное ревью) — только
   R-модели: `opencode-go/gemini-4-argon-contributor`, `opencode-go/muse-spark-1.3-contributor`.
   Остальное (механика, рутина, доки) — E-модели. Список R-моделей правит автор
   (решение D19 в `DECISIONS.md`).
