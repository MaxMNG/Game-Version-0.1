# DECISIONS.md — журнал архитектурных решений (ADR)

Фиксируем важные решения, чтобы не переобсуждать их между сессиями.
Формат: дата, решение, контекст/причина, статус.

## D1. Движок: Godot 4.7.2 stable, рендерер Compatibility

- **Дата:** 2026-10-17
- **Контекст:** 2D-игра с минималистичным визуалом, целевая платформа — Steam (PC).
- **Решение:** Godot 4.7.2, `gl_compatibility`, окно 1920x1080.
- **Причина:** максимальная совместимость (слабые ПК, Steam Deck), все нужные шейдеры работают и в Compatibility.
- **Статус:** Принято.

## D2. Проект Godot — в подпапке `Game/`

- **Дата:** 2026-10-17
- **Контекст:** корень репозитория — одновременно Obsidian-хранилище с GDD и документацией.
- **Решение:** `project.godot` в `Game/`, документация в `Docs/`, GDD в `References/`.
- **Причина:** чистое разделение кода и контента; `.godot/` не мешает Obsidian.
- **Статус:** Принято.

## D3. MCP для Godot: godot-mcp (tugcantopaloglu), а не godot-ai (hi-godot)

- **Дата:** 2026-10-17
- **Контекст:** нужен MCP-сервер для автономной разработки агентом.
- **Решение:** `F:/GODOT/MCP/godot-mcp` (157 инструментов, headless + TCP к запущенной игре).
- **Причина:** не требует открытого редактора и `uv` (не установлен); уже собран; `game_eval`
  покрывает любые runtime-задачи. godot-ai пересмотрим на этапе MVP (тест-фреймворк, работа в редакторе).
- **Статус:** Принято.

## D4. Контент-таблицы: CSV + конвертер в .tres

- **Дата:** 2026-10-17
- **Контекст:** таблицы слов/предложений/реплик геймдизайнер редактирует массово.
- **Решение:** источник истины — `Content/*.csv`; конвертер `Tools/convert_content.py` → `.tres` в `Game/resources/`.
- **Причина:** CSV удобно править в Excel/Google Sheets; игра работает с родными ресурсами Godot.
- **Статус:** Принято.

## D5. Языки: документация и комментарии — русские; игра и идентификаторы — английские

- **Дата:** 2026-10-17
- **Решение:** `Docs/`, AGENTS.md, CodeStyle.md и комментарии в коде — на русском;
  UI/реплики/слова в игре и все идентификаторы — на английском.
- **Статус:** Принято.

## D6. Архитектура: автолоады Events / Configs / Trust / Game

- **Дата:** 2026-10-17
- **Контекст:** требования GDD — одна базовая сцена, изолированные системы, ноль хардкода.
- **Решение:** состояние в автолоадах; общение — сигналами `Events`; числа — в `.tres` через `Configs`;
  сцены состояний подменяются внутри `Main.tscn`; наследование от `BaseMinigame` для мини-игр.
- **Статус:** Принято.

## D7. Прототип — без звука и без сейвов

- **Дата:** 2026-10-17
- **Контекст:** цель прототипа — тест механик и связки с ИИ-агентом.
- **Решение:** звук не добавляем; каждая игра новая (сохранений нет).
- **Статус:** Принято (пересмотреть на MVP).
